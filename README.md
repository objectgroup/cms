# Documentation for the content management system (cms)

## A description of the cms
This content management system(cms) makes a static website in a local directory of your choosing. Given an initial set up the cms will make a website with a home page which links to an about page, a generated RSS feed and the most recent page of notes. The notes can be updated monthly and will automatically be organised into a navigable archive as more notes are added, as described below in the structure of the website section. Although you can skip updates for months and the cms code will cope fine with that, you can't add more than one post in a month, although you can update a post at any time. You can miss monthly updates for years then the cms will just display what it has. The cms comes with a style sheet so that you have a neat layout but one that you can customise to your needs and the html that the cms generates is accessible html 5.  You can add a favicon to the images/logo directory. The website generated by this cms has been designed to be for a text only website however it is possible to add pictures with customisation of the style sheet.  

## The structure of the website
The homepage links to the most recent year with all of it's monthly updates.  In a year page the most recent month is given in full at the top of the page and the rest of the entries in order below in full. The year pages can be navigated with links at the bottom of the page to the previous year and the next year, given they exist. The title of the month entries on the year page is always a hyperlink to a standalone page of that month's entry with links at the bottoms of that page to the previous and next month entries. Both the standalone month pages and the year pages have a breadcrumb trail to navigate back to the home page and a footer with links to the RSS feed and your email and a statement about the site that you can customise.  

## The setup of the cms
After an initial setup the csm will only require a text file of the monthly update with an appropriate file name (year-month) to be added to a directory named 'blogs' and meta data to be added to a meta.csv and yearmeta.csv for that entry.    

### The initial set up
After folking the cms project to a directory you do your web development in, you should have the cms.py and a css stylesheet in a directory called 'style'. At the same level as the cms.py file and the style directory that contains the stylesheet.css, the directories that you need to add are: 
- an "images" directory with another directory inside called "logo" and within that a favicon of your choosing.
- a 'blogs' directory where the blog posts as text files will reside. 
Then you need to create the following files:

### cmsc.py
In the same directory as the cms.py create a file called cmsc.py (standing for : content management system constants)  and add the following custom constants. 

websiteName = the name of your website in quotation marks e.g. "[object][group]"
websiteDomain = the name of your website domain in quotation marks e.g. "https://objectgroup.uk"
websiteEmail = the name of your email in quotation marks  e.g. "lisa@objectgroup.uk"
websiteDescription = a description of the website in quotation marks e.g. "A frivolous cartoonist in East Anglia"
websiteMetaIndex = a comma separated list of words that describe your website in quotation marks e.g. "comics, cartoon, East Anglia, Britain, England, UK"
websiteLanguage = the locale code of the website in quotation marks e.g. "en_GB"
faviconURL = the absolute location of the favicon in quotation marks e.g. "https://objectgroup.uk/images/logo/Objectgroup-cherry.svg"
faviconPathIndex = the relative location of the favicon that is one directory up, all in quotation marks e.g. "../images/logo/Objectgroup-cherry.svg"
styleSheetPathIndex =  "../style/stylesheet.css"
rssFileName = a name you choose of the rss file in quotation marks e.g. "rss.xml"
numberOfRssItems = the number of most recent rss items you wish have in the rss file given as an positive integer e.g. 15
footerText = a description of the website that will be used in the footer of each page all in quotation marks e.g. "This is the website of a person who takes things they care about and makes comic stories around them. "

### The meta files
Then in the same directory as the cms.py create files called meta.csv and meta-year.csv. 

The meta.csv is a place to describe the monthly update pages. meta.csv has three values per line, the month's filename which is in the year-month format as defined in the "naming a note file" bellow, the meta keywords that are up to 10 keywords that describe the webpage separated by spaces and the meta title which is a description of the content of your page in around 60 characters including spaces.  
The comma separated format of meta.csv is : month's filename, meta keywords, meta title  
The values given are for the meta title are used as the update description in the RSS feed as well as the "description" meta tag for the update page. The values for the meta keywords are used for the "keyword" meta tag which is not widely used these days but it will also be used as a tag navigation option for future versions of the cms. 

The meta-year.csv is a place to describe the year pages that are a collection of the monthly updates for that year. meta-year.csv has three values per line, the year as a four digit figure e.g. 2025, the meta keywords that are up to 10 keywords that describe the webpage separated by spaces and the meta title which is a description of the content of your page in around 60 characters including spaces.   
The comma separated format for the meta-year.csv is: year, meta keywords, meta title 
The values given are for the meta title are used as the "description" meta tag for the update page. The values for the meta keywords are used for the "keyword" meta tag which is not widely used these days but it will also be used as a tag navigation option for future versions of the cms. 

The cms will not generate a website if any of the meta details for year or month are missing. 

### The about.txt
In the same directory as the cms.py create an about.txt page that will describe the website. See the section about how the cms handles text files to guide how you write the text. 

### Making notes in the 'blog's' directory   
To make a note in the 'blogs' directory simply put the text of the note with a file name. The filename of a note is the year as a four digit number, a hyphen and then the month as a number with no preceding zeros, e.g. January is 1 and December is 12. See the section about how the cms handles text files to guide how you write the text. 

### How the cms handles text files.
The cms will add some html to the text of the about.txt and notes. It will wrap paragraph tags around blocks of text identifying a start of a line and ending when it identifies a newline. So there is no need to separate paragraphs with an extra line.  The cms will also convert any apostrophes to the html "&apos"  instead. 
However any other html required for example links within the text need to be added by using html directly into the text e.g. ```<a href="website address">link text</a>```. Other html you may wish to add are quotes that are like this: 
```
<q cite="source of quotation url">quote</q> 
Or for a quote longer than one sentence like this:
<blockquote cite="source of quotation url">
    <p>quote</p>
 </blockquote> 
<p>author of source <cite>Name of document of source</cite></p>
```
### Running the csm (generating the site)
With all the files above in place it is time to run the cms code. To do this on the command line and within the directory of the cms.py file, run ```./cms.py```
The resulting website should be in a file called "notes" that is in the same directory as the cms.py.
